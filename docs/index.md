## One contract, one viewer

<div class="lx-feature-grid">
<div><h3>One JSON contract</h3><p>Laravel, Python and Node.js packages all write the same versioned <code>laranex-schema</code> document, with a JSON Schema, a validator and shared conformance fixtures.</p></div>
<div><h3>One shared viewer</h3><p>A React Flow ERD with ELK layout, separate foreign-key and ORM layers, indexes, constraints, diagnostics and drift — the same in every host.</p></div>
<div><h3>Database, declared or both</h3><p>The contract records whether metadata came from the database, the ORM or both, what each source covered, and where they disagree.</p></div>
<div><h3>No Node.js at runtime</h3><p>Laravel and Python hosts serve a prebuilt static bundle that runs under a strict Content-Security-Policy.</p></div>
</div>
